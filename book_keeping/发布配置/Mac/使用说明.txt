本地记账助手使用说明
====================

一、这是什么程序
----------------

这个程序只在本机运行，用来：

1. 把旧流水 Excel 转换成“标准化输入数据.xlsx”；
2. 把标准化数据转换成“记账分析报告.xlsx”；
3. 在网页中确认无法自动判断的日期、人员、金额和拆分记录；
4. 自动保留异常处理进度，下次上传相同流水时继续使用；
5. 导出小型“规则改进样本.json”，交给程序维护者改进自动识别规则。

文件不会上传到互联网。网页地址是本机地址 127.0.0.1，其他人无法通过互联网访问。


二、运行环境
------------

本文件夹已经包含程序所需的 Node.js 和 Excel 处理组件，通常不需要安装任何环境。

当前便携版为 macOS Intel 版本。在 Apple 芯片 Mac 上，如果系统提示安装 Rosetta，可按照系统提示安装后再试。Windows 电脑不能直接运行这个 .command 文件，需要另做 Windows 版本。

重要：请完整解压“记账程序-Mac版.zip”，不要只复制“启动记账程序.command”。程序文件夹较大是正常的，因为其中包含本地 Excel 处理环境。


三、第一次启动
--------------

1. 打开整个记账程序文件夹。
2. 双击“启动记账程序.command”。
3. 如果 macOS 提示无法验证：
   - 关闭提示；
   - 右键“启动记账程序.command”；
   - 选择“打开”；
   - 再点击一次“打开”。
4. 终端窗口会显示“正在启动本地记账助手”，随后浏览器自动打开。
5. 使用期间不要关闭这个终端窗口；关闭窗口就是停止程序。

如果网页没有自动出现，可以在浏览器输入：

http://127.0.0.1:3765


四、两种处理方式
----------------

方式 1：原始数据 → 标准输入

- 选择旧流水 .xlsx；
- 勾选“厂收支明细”“自己明细”“义乌流水”等需要导入的工作表；
- 可以单选，也可以多选；
- 输出“标准化输入数据.xlsx”。

方式 2：标准输入 → 最终结果

- 选择程序生成、并经过复核的“标准化输入数据.xlsx”；
- 输出“记账分析报告.xlsx”；
- 报告包含简洁流水、日汇总、月汇总、年汇总和完整数据。

也可以同时选择两步。此时上传原始流水后，会一次生成两份 Excel。


五、异常数据怎么处理
--------------------

红色高优先级：缺少第二步统计所需的可靠信息，处理前不进入正常统计。

黄色低优先级：通常只是日期不完全确定。即使暂不修改，也会按候选日期或报表末尾的“无日期”区块统计。

每张异常卡片可以：

- 直接修改日期、人员、正负金额、交易类型、分类和备注；
- 点击一个输入框，再点击上方分词快速填入；
- 点击“增加一笔收入或支出”，把混合说明拆成多行；
- 点击“确认并纳入”“暂不处理”或“忽略”。

金额规则：

- +20 表示收入 20；
- -20 表示支出 20；
- 金额正负号会自动决定收入或支出；
- 分类可以留空；
- 日期也可以留空，之后会进入“无日期”区块。


六、自动保存和更新 Excel 的顺序
------------------------------

每次点击“确认并纳入”“暂不处理”或“忽略”后，处理决定会立即保存到本机。修改“已处理数据”中的输入框后，程序也会稍等片刻自动保存。

页面会显示以下状态之一：

- 正在把异常处理进度保存到本机；
- 异常处理进度已自动保存；
- 自动保存失败。

自动保存只保存进度，不会每次都重新生成大型 Excel。

准备下载最新结果时，请点击：

“保存所有修改并更新 Excel”

然后程序会重新计算：

- 标准化输入数据.xlsx；
- 如果选择了连续处理，同时更新记账分析报告.xlsx。

所以正确顺序是：先处理若干异常 → 确认页面显示已自动保存 → 点击保存并更新 Excel → 下载最新文件。


七、本地保存了什么
------------------

“用户数据”文件夹里有两类小文件：

1. 异常处理进度.json
   用于下次继续处理。包含异常原文、原工作表和单元格、处理方式，以及必要的编辑结果。

2. 规则改进样本.json
   只包含“确认并纳入”和“忽略”的异常样本。“暂不处理”没有确定答案，不会作为 true value。

程序不会在这两个文件中保存普通流水、整份原始 Excel、最终分析报告或无关操作日志。

重新上传相同流水时，只有工作表、单元格和原始内容完全一致的异常才会恢复旧答案。原文发生变化时会重新交给用户确认，避免套错答案。


八、怎么把结果交给程序维护者
----------------------------

1. 在网页结果区点击“导出规则改进样本”。
2. 浏览器会下载“规则改进样本.json”。
3. 把这一个 JSON 文件发给程序维护者即可。

通常不需要发送原始流水、标准化输入数据或记账分析报告。规则改进样本仍可能包含异常原文和人员名称，发送前应确认接收者可信。


九、下载文件
------------

- 点击文件名：保存到浏览器默认 Downloads（下载）文件夹；
- 点击“选择文件夹保存全部结果”：可以自行选择保存位置；
- 处理异常后必须点击“保存所有修改并更新 Excel”，再下载才是最新计算结果。


十、换电脑、升级或备份
----------------------

把程序交给另一个人：复制整个文件夹。

备份处理进度：复制“用户数据”文件夹。

以后收到新版本：先备份原来的“用户数据”文件夹，再替换程序；不要删除已经使用过的异常处理进度。

如果希望给另一个完全独立的使用者一份干净程序，应清空“用户数据”中的个人记录，只保留程序提供的空白 JSON 文件。


十一、常见问题
--------------

1. 双击没有反应
   右键启动文件并选择“打开”。不要把启动文件单独移出文件夹。

2. 提示程序文件不完整
   重新复制整个文件夹。复制软件或云盘可能漏掉“程序文件/.runtime”等隐藏内容。

3. 网页说端口被占用
   程序可能已经启动。直接打开 http://127.0.0.1:3765，或者先关闭旧的启动终端窗口。

4. 关闭网页后异常结果会不会丢
   页面已经显示“已自动保存”的处理结果不会丢。尚未选择处理方式的临时输入不保证保存。

5. 为什么点确认后下载的 Excel 没立刻变化
   点击三个处理按钮只自动保存进度。请再点击“保存所有修改并更新 Excel”。

6. Excel 无法统计某条记录
   检查人员和金额是否填写，金额是否为非零数字。日期可以为空。

7. 如何停止程序
   关闭启动时打开的终端窗口。
