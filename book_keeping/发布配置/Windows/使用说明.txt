本地记账助手（Windows 版）使用说明
==================================

一、开始前要做什么
------------------

本版本适用于 Windows 10/11 64 位电脑，已经自带 Node.js 和 Excel 处理组件。
不需要安装 Node.js、Python，也不需要管理员权限。电脑上有浏览器即可；安装 Excel
只用于打开最后生成的 .xlsx，不影响程序本身运行。

请先把 ZIP 完整解压，再运行。不要直接在压缩包预览窗口中双击，也不要只复制
“启动记账程序.bat”，否则程序找不到后面的“程序文件”和“用户数据”。


二、第一次启动
--------------

1. 双击“启动记账程序.bat”。
2. 等待几秒，默认浏览器会自动打开本地记账页面。
3. 使用期间不要关闭黑色启动窗口；关闭它就会停止本地服务。
4. 用完后可以直接关闭黑色窗口。

如果浏览器没有自动打开，请在浏览器地址栏输入：

http://127.0.0.1:3765

这个地址只指向当前电脑。上传的 Excel 不会经过互联网，也不会自动传给维护者。


三、Windows 安全提示
--------------------

如果 Windows 显示“Windows 已保护你的电脑”：

1. 确认这个压缩包来自可信的程序维护者；
2. 点击“更多信息”；
3. 点击“仍要运行”。

如果公司安全软件禁止运行未知批处理文件，请联系电脑管理员。不要为了运行程序
长期关闭杀毒软件或系统安全功能。


四、两种处理功能
----------------

功能 1：原始数据 → 标准输入

- 选择旧流水 .xlsx；
- 勾选要读取的工作表，可以单选或多选；
- 输出“标准化输入数据.xlsx”；
- 无法自动判断的内容会显示在网页异常处理区。

功能 2：标准输入 → 最终结果

- 选择标准化输入数据；
- 输出“记账分析报告.xlsx”；
- 报告包含简洁流水、日汇总、月汇总、年汇总和完整数据。

也可以同时选择两个功能。此时上传原始流水后，程序会先标准化，再生成报告。


五、异常数据处理
----------------

红色高优先级：缺少可靠金额或人员等关键数据，处理前不进入正常统计。

黄色低优先级：通常只是日期不完全确定。即使暂不修改，也可以按候选日期或
“无日期”区块进入统计。

每张异常卡片可以：

- 修改日期、人员、正负金额、交易类型、分类和备注；
- 先点击输入框，再点击分词快速填写；
- 增加多行，把一条混合说明拆成多笔；
- 点击“确认并纳入”“暂不处理”或“忽略”。

金额直接使用正负数：+20 是收入 20，-20 是支出 20。分类和日期可以留空。


六、什么时候更新下载文件
------------------------

点击三个异常处理按钮后，处理决定会立刻自动保存到“用户数据”文件夹，但不会
每次都重建大型 Excel，避免电脑卡顿。

需要下载最新结果时，再点击网页中的：

“保存所有修改并更新 Excel”

随后程序会更新：

- 标准化输入数据.xlsx；
- 如果本次同时选择了两步，也会更新记账分析报告.xlsx。


七、换电脑、升级和交给维护者
----------------------------

“用户数据”文件夹里只有两个小型 JSON：

- 异常处理进度.json：用于下次继续；
- 规则改进样本.json：保存已经确认的 true value，供后续改进规则。

备份时复制整个“用户数据”文件夹。升级程序前，也先备份这个文件夹。

要帮助维护者改进识别规则时，在网页点击“导出规则改进样本”，只把下载的
“规则改进样本.json”发给维护者。它可能包含异常原文和人员姓名，请只发给
可信接收者。通常不需要发送整份流水或最终报告。

Mac 版与 Windows 版使用相同 JSON 数据格式，因此两边导出的规则样本可以合并处理。


八、出问题怎么办
----------------

1. 双击“检查运行环境.bat”。
2. 等待检查完成。
3. 如果失败，把以下文件发给维护者：

   - Windows运行环境检查结果.txt
   - 启动错误日志.txt（如果存在）

这些日志只记录系统架构、运行环境版本和错误信息，不保存整份流水 Excel。

常见问题：

- 网页打不开：确认黑色启动窗口没有关闭，再访问 http://127.0.0.1:3765。
- 提示端口占用：程序可能已经启动，直接打开上面的地址。
- 提示文件不完整：删除当前解压副本，重新完整解压 ZIP。
- 下载结果没有更新：先点击“保存所有修改并更新 Excel”，再下载。


九、文件夹说明
--------------

启动记账程序.bat       平时双击这个
检查运行环境.bat       只有启动失败时使用
使用说明.txt           本说明
版本信息.txt           程序和运行环境版本
程序文件/              程序与 Windows 运行环境，不要手动改动
用户数据/              异常处理进度，需要备份
