# 本地记账助手

这是一个只在本机运行的两阶段记账程序：输入 `.xlsx`，输出新的 `.xlsx`。日常使用不需要写命令。

## 一键打开

1. 返回上一层文件夹，双击 `启动记账程序.command`。
2. 浏览器打开“本地记账助手”。
3. 选择第①步、第②步，或者同时选择两步连续处理。
4. 默认下载到浏览器的 `Downloads`；支持的浏览器也可以点“选择文件夹保存全部结果”。

文件不会上传到互联网。每次任务的临时文件保存在程序内部的 `runs/任务编号/`；关闭启动程序所在的终端窗口即可停止服务。

便携版已经包含 Node.js 与 Excel 处理组件，普通用户无需安装环境。异常处理历史保存在上一层的 `用户数据/`，升级程序文件时不要覆盖这个文件夹。

如果 macOS 第一次阻止双击，请右键 `启动记账程序.command`，选择“打开”，再确认一次。

## 第①步：原始数据 → 标准输入

上传原始流水工作簿后，网页会列出全部工作表标签。可以单选或多选当前已配置的三张表：

- `厂收支明细`
- `自己明细`
- `义乌流水`

其他历史汇总、库存和辅助表会显示为灰色，不会误导入。输出文件为 `标准化输入数据.xlsx`。

日期处理规则：

- 空白日期夹在相邻两天之间时，自动继承上一日期。例如上方是 `2026-06-05`、下方是 `2026-06-06`，中间空白行归入 `2026-06-05`。
- 上下日期跨度较大时，只生成候选日期范围，不强行猜某一天。
- 无法形成范围时，交给用户在网页填写。
- 红色高优先级异常缺少可靠统计字段，处理前不会进入最终收支统计。
- 黄色低优先级异常仅日期不完全确定：有候选范围时先按范围起始日计入，完全没有日期时计入报表末尾的“无日期”区块；用户仍可稍后调整。

## 网页异常复核

第①步完成后，异常区会自动填入已经确定的日期、人员、金额等字段。高优先级始终排在低优先级前面。每组异常可以：

- 直接修改表格；
- 点一个单元格，再点原始描述的分词快速插入；
- 用“增加一笔收入或支出”把一条混合描述拆成多笔；
- 选择“确认并纳入”“暂不处理”或“忽略”。

每次选择处理方式后，网页会把必要的异常原文、决定和编辑结果自动保存到本机。普通流水和整份工作簿不会写入历史文件。重新上传原始内容完全一致的流水时会自动恢复旧决定。

“导出规则改进样本”只导出确认与忽略的异常；暂不处理不是确定答案，不会作为 true value。自动保存不会立即重建 Excel，仍需点击“保存所有修改并更新 Excel”统一重新计算。

金额直接使用正负号：`+20` 表示收入，`-20` 表示支出，并自动更新交易类型。分类可以不填。已经选择处理方式的数据会移到“已处理数据”区域，仍可重新修改。

如果同时选择第①步和第②步，网页会立即生成两份文件；保存异常处理结果后，还会重新计算并同时更新 `标准化输入数据.xlsx` 与 `记账分析报告.xlsx`。

## 第②步：标准输入 → 最终结果

上传复核后的 `标准化输入数据.xlsx`，输出 `记账分析报告.xlsx`。最终文件包含五张工作表：

- `简洁流水`：按日期列出记账，列顺序为日期、人员、金额、交易类型、分类、三个空白分隔列、备注、原始描述；每天后面有日收入/支出/净收支，每月末有人月汇总和月总计，年末有人年汇总和年度总计。
- `日汇总`：逐日先列个人收入、支出和净收支，再列当日总体汇总。
- `月汇总`：逐月先列个人收入、支出和净收支，再列当月总体汇总。
- `年汇总`：逐年先列个人收入、支出和净收支，再列当年总体汇总。
- `完整数据`：保留记录 ID、交易组 ID、来源工作表、来源单元格、异常优先级和统计状态等技术字段，便于追溯。

汇总统计数据状态为 `有效` 的普通收入/支出，也会临时纳入黄色低优先级记录；红色高优先级与忽略记录不计入。无日期记录在各汇总表末尾单列个人与总体金额。某日、某月或某年没有 USD 收支时，该期间不会显示空白 USD 区块。期初余额、内部转账和换汇不会混入普通收支。

## 开发和排错

也可以在终端启动网页：

```bash
npm run app
```

底层程序仍可独立运行：

```bash
# 创建空白模板
node prepare_data.mjs template --output outputs/标准输入模板.xlsx

# 只导入指定工作表
node prepare_data.mjs migrate \
  --input 流水.xlsx \
  --output outputs/标准化输入数据.xlsx \
  --sheets-json '["厂收支明细","自己明细"]'

# 由标准输入生成最终结果
node generate_report.mjs \
  --input outputs/标准化输入数据.xlsx \
  --output outputs/记账分析报告.xlsx

# 运行自动测试
npm test
```
