# 学习笔记

## 为什么不在 `main.py` 里直接调用 SDK

直接调用虽然短，但会把参数加载、业务规则、异常处理和厂商对象混在一起。拆出 `TextGenerator` Protocol 后，单元测试只需一个十行 Fake，就能验证请求是否正确传递。

## 流式输出的状态变化

流式响应不是“一次返回一个完整答案”，而是按事件产生增量。Provider 只转发 `response.output_text.delta` 的 `delta`，入口逐段显示。生产环境还需要处理客户端断开和最终 usage 统计。

## 重试边界

OpenAI SDK 负责网络级重试；Service 不再套一层无差别重试，避免一次请求被成倍执行。有副作用的工具调用尤其不能无条件重试。
