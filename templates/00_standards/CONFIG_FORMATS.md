# 配置格式职责

| 格式 | 保存内容 | 不应保存 |
|---|---|---|
| Markdown | 项目、模型、Prompt 和学习说明 | 运行时密钥 |
| YAML | 可读的运行参数与场景预设 | 真实 API Key |
| TOML | Python 包、依赖和工具配置 | 频繁变化的业务输入 |
| `.env.example` | 环境变量名称与无敏感示例 | 真实 `.env` 值 |
| JSONL | 一行一个评测、批处理或微调样本 | 需要人工阅读的长文档 |
| Jinja2 | 带受控变量的 Prompt | 未转义的任意代码 |

## 推荐覆盖顺序

`default.yaml` 提供完整安全默认值，`presets/*.yaml` 只覆盖少数字段，环境变量只提供密钥和部署差异。真实项目如果增加 CLI 临时覆盖，必须在日志中保存最终解析后的配置。

不建议同时修改 `temperature` 和 `top_p`。不同模型支持的参数不同，Provider 只应发送非空且已确认支持的参数。
