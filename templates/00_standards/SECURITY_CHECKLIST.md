# 大模型应用安全检查表

## 密钥与日志

- [ ] `.env`、凭证、Cookie 和私有证书均被 `.gitignore` 忽略。
- [ ] 日志不打印 API Key、完整身份证号、密码或访问令牌。
- [ ] 测试使用 Fake/Mock，集成测试需要显式环境变量才能运行。

## 输入、输出与数据

- [ ] 输入有长度、类型和文件大小限制。
- [ ] 敏感数据发送给外部 Provider 前经过授权和最小化处理。
- [ ] 结构化输出在进入数据库或业务系统前再次校验。
- [ ] RAG 回答能够追踪到证据，空证据时不编造答案。

## 工具与 Agent

- [ ] 有副作用的工具经过审批、鉴权或幂等控制。
- [ ] 模型不能直接拼接 SQL、Shell 或文件路径并执行。
- [ ] 工具调用次数、重试次数和总耗时都有上限。
- [ ] Handoff 和工具参数保留审计记录。
